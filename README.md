## Important notes
This is a static frontend. CRM login is visible as a placeholder only and is not connected to authentication. Forms open WhatsApp or provide enquiry guidance; there is no live hotel/flight inventory, payment gateway, saved booking database, or live visa processing integration. Hotel imagery is illustrative unless explicitly verified. Confirm rates, availability, property details and visa requirements before booking.

## Deploy on GitHub Pages
Keep `index.html` in the repository root and preserve the `assets/` folder structure. Enable GitHub Pages from the repository's main branch/root.
