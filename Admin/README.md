# Meeqan Admin Panel — Preview

Open `index.html` in this folder to view the admin dashboard. The current version is a client-side demo using browser localStorage, with example records for demonstration.

Included modules:
- Dashboard overview and quick actions
- Booking list, status updates, search/filter and CSV export
- Hajj/Umrah package management
- Hotel/room listing management
- Flight offers (enquiry-only, no ticket issuance)
- Tours and Ziyarat
- Public website service cards
- Inquiry tracking and CSV export
- Customer section placeholder
- Staff/admin role planning (not real user accounts)
- Reports and business contact settings

No real authentication, database, payment processing, email delivery, or passport/document upload is implemented. Do not enter real or sensitive customer data. Connect Supabase Auth + Row Level Security and a database before production use.
